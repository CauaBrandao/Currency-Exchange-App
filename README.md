# 💱 Currency Exchange App

> Um aplicativo web moderno e intuitivo para conversão de moedas em tempo real, desenvolvido com React e Vite.

## 📋 Sobre o Projeto

O **Currency Exchange App** foi criado para facilitar a vida de quem precisa converter valores entre diferentes moedas internacionais de forma rápida, precisa e com uma interface limpa. A aplicação consome dados atualizados do mercado financeiro para garantir taxas de câmbio precisas.

---

## ✨ Funcionalidades

* **Conversão em Tempo Real:** Converta valores instantaneamente entre várias moedas globais.
* **Interface Responsiva:** Design otimizado tanto para dispositivos móveis quanto para desktops.
* **Seleção Dinâmica de Moedas:** Busque e selecione facilmente as moedas de origem e destino.
* **Alta Performance:** Construído com Vite para tempos de carregamento e resposta ultrarrápidos.

## 📦 Como Rodar o Projeto Localmente

Siga os passos abaixo para configurar e executar o projeto em sua máquina:

### Pré-requisitos
Certifique-se de ter o **Node.js** e o **npm** (ou yarn/pnpm) instalados.

### Passo a passo

1. **Clone o repositório:**
   ```bash
   git clone [https://github.com/CauaBrandao/Currency-Exchange-App.git](https://github.com/CauaBrandao/Currency-Exchange-App.git)
Entre na pasta do projeto:

Bash
cd Currency-Exchange-App
Instale as dependências:

Bash
npm install
Inicie o servidor de desenvolvimento:

Bash
npm run dev
Abra o navegador e acesse http://localhost:5173 (ou a porta indicada no seu terminal).

📜 Scripts Disponíveis
npm run dev — Inicia o servidor de desenvolvimento.

npm run build — Cria a versão otimizada da aplicação para produção na pasta dist/.

npm run preview — Visualiza a versão de produção localmente.

npm run lint — Executa a verificação de código (linter).
